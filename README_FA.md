# Arbab Wizard — نسخه قابل انتشار آزمایشی

این بسته شامل یک Cloudflare Worker نصب‌کننده و تست‌های شبیه‌سازی‌شده است. نصب واقعی روی حساب Cloudflare انجام نشده؛ بنابراین «بدون باگ» یا «تأییدشده در محیط واقعی» نیست. **پنل نصب‌شده فقط مدیریت لینک‌های اشتراک موجود است و موتور VPN یا Xray ندارد.**

## نصب یک‌باره Wizard بدون GitHub و بدون نرم‌افزار

1. در `dash.cloudflare.com` به **Workers & Pages → Create → Worker** بروید و یک Worker به نام `arbab-wizard` بسازید.
2. در **Edit code** تمام محتوای فایل `arbab-installer-worker.js` را جایگزین کد Worker کنید و **Deploy** را بزنید.
3. در تنظیمات Worker، بخش **Settings → Variables and Secrets** یک **Secret** با نام `INSTALLER_KEY` و مقدار تصادفی حداقل ۲۴ کاراکتری بسازید (ترجیحاً ۳۲ یا بیشتر). این مقدار فقط متعلق به شماست و نباید در GitHub عمومی یا چت ارسال شود.
4. آدرس `https://arbab-wizard.<your-subdomain>.workers.dev` را باز کنید.
5. روی **دریافت توکن از Cloudflare** بزنید. صفحه رسمی Cloudflare باز می‌شود و مجوزهای Workers Scripts Edit، D1 Edit و Account Settings Read پیشنهاد می‌شوند. **مجوزها و محدوده حساب را قبل از تأیید کنترل کنید**؛ در صورت امکان توکن را فقط به حساب موردنظر محدود کنید. توکن را کپی کنید.
6. **Account ID** را از صفحه حساب Cloudflare (معمولاً بخش Account details) کپی کنید.
7. کلید خصوصی نصب‌کننده، توکن، Account ID، نام Worker و رمز مدیریت قوی را در فرم وارد کنید و **نصب پنل** را بزنید.
8. اگر همه APIها موفق باشند، لینک `/panel` نمایش داده می‌شود. اگر خطا آمد، پیام خطا را بدون ارسال توکن بررسی کنید.

## نکات امنیتی

- کلید `INSTALLER_KEY` برای جلوگیری از نصب بدون اجازه است. برای محیط عمومی از **Cloudflare Access** نیز استفاده کنید.
- توکن در D1 یا KV ذخیره نمی‌شود؛ هنگام نصب از مرورگر به Worker و از Worker به API Cloudflare ارسال می‌شود.
- بهتر است بعد از نصب، توکن را **Revoke** کنید و در صورت عدم نیاز Worker نصب‌کننده را غیرفعال کنید.
- در نصب مجدد با همان نام، رمز مدیر و کلید نشست تغییر می‌کند. دیتابیس قبلی به شرط یکسان بودن نام قابل استفاده مجدد است.
- ایجاد اولیه خود Wizard همچنان یک‌بار دستی است؛ یک صفحه GitHub Pages به‌تنهایی نمی‌تواند بدون زیرساخت امن، توکن را به Cloudflare منتقل کند.

## تست‌ها

اجرای `node test.mjs` در محیط توسعه ۹ بررسی را با Cloudflare API شبیه‌سازی‌شده انجام می‌دهد. این تست‌ها **جایگزین تست نصب واقعی نیستند**.
